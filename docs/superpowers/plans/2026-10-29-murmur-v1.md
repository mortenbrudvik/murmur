# Murmur v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Murmur v1 — a Windows tray app where holding a hotkey records speech, Whisper transcribes it locally on the GPU, and the text is pasted into the focused app.

**Architecture:** Hybrid WPF solution from the owner's `wpf-scaffold` template. `Murmur.Core` holds the dictation pipeline (keyboard hook → hotkey matcher → state machine → audio capture → Whisper → post-processors → clipboard paste → history) with every Win32/audio/GPU edge behind a small interface so the logic is unit-tested. `Murmur.UI` hosts the native pill overlay, tray icon and app wiring; the main window (History / Vocabulary / Settings) is React in WebView2, talking to Core over the template's MediatR IPC bridge.

**Tech Stack:** .NET 10 / C# 14, WPF + WPF-UI 4, Autofac, MediatR 12, Serilog, CommunityToolkit.Mvvm, H.NotifyIcon.Wpf, NAudio 2, Whisper.net (+ `Whisper.net.Runtime.Cuda`, `.Runtime.Vulkan`, `.Runtime`), System.Windows.Extensions (SoundPlayer); React 19 + Vite + TypeScript + Vitest; xUnit v3 + NSubstitute + Shouldly + Microsoft.Extensions.TimeProvider.Testing; System.Speech (tests only).

**Spec:** `docs/superpowers/specs/2026-10-29-murmur-design.md`

## Global Constraints

- Build settings from the template: `net10.0-windows10.0.26100.0`, Nullable on, `TreatWarningsAsErrors=true`. Builds must have zero warnings.
- Template conventions: one MediatR request + handler per IPC call, registered in `App.xaml.cs` via `ApiRegistry`; C# → JS events via `ApiEventAggregator`; `Log.ForContext<T>()`; file-scoped namespaces; atomic temp-file + `File.Move` writes for JSON files (as in the template's `SettingsService`).
- `JsonUtils` (in `Murmur.Common`) gets `new JsonStringEnumConverter(JsonNamingPolicy.CamelCase)` in both option sets; all JSON (IPC and files) goes through `JsonUtils`.
- English only: Whisper language `"en"`.
- Local only. The only network access is the one-time model download from `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin`.
- Runs unelevated. Never request admin rights or `uiAccess`.
- Data root `%LOCALAPPDATA%\Murmur\`: `settings.json`, `vocabulary.json`, `history.jsonl`, `models\`, `audio\`, `Logs\`.
- Default hotkey Right Ctrl (VK `0xA3`). Tap threshold 300 ms. Stray-tap guard 8 s. Hands-free limit 10 min.
- Silence: speech detector found no speech, or Whisper `MaxNoSpeechProbability >= 0.6` → paste nothing, save nothing.
- Clipboard restore delay 500 ms. Every Murmur clipboard write is excluded from Win+V history and cloud clipboard.
- Pill copy, exact: `Loading model…`, `Copied — press Ctrl+V`, `Saved to history`, `Microphone unavailable`, `Transcription failed`. Notices stay 1.5 s, then the pill hides.
- Colors (from the mockups): pill background `#E0161820`, pill border `#1FFFFFFF`, recording dot `#FF5A5F`, waveform/accent `#8FB3FF`, app background `#1C1F27`, sidebar `#181A21`, cards `#22262F`, text `#DFE3EE`, muted text `#9AA3B8`, error `#FF6B6B`.
- Audio is not kept unless the "Keep audio recordings" setting is on.
- Every commit message ends with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Back-to-back dictations.** A second paste that starts while the first is still waiting to restore the clipboard must not snapshot Murmur's own transcript as "the previous clipboard"; the owner's original clipboard must be what remains. → Task 10 `InsertAsync_TwoConcurrentInserts_RestoresOriginalClipboard`.
2. **Modifiers still held at paste time** (combo hotkeys, or Shift held while finishing). Ctrl+V must wait for modifiers to be released, or the target receives Ctrl+Shift+V. → Task 10 `InsertAsync_WaitsForModifiersReleasedBeforeSendingPaste`.
3. **Non-text clipboard contents** (images, copied files, app-specific formats) must survive a dictation. → Task 10 `SnapshotRestore_RoundTripsCustomFormatAndText`.
4. **Replacement rules with `$`, regex metacharacters, or punctuation** ("c sharp" → "C#", "dollar sign" → "$") must be applied literally. → Task 3 `ApplyRules_*` tests.
5. **Microphone missing, unplugged or failing to start** must not leave Murmur stuck recording: show `Microphone unavailable` and return to idle. → Task 12 `RecorderStartFails_ShowsMicNoticeAndReturnsIdle`.

```csharp
public sealed class DictationStateMachine(DictationTimings timings)
{
    public DictationState State { get; }
    public bool IsActive { get; }                 // State != Idle
    public bool SpeechSeen { get; }
    public DictationAction OnHotkeyDown(DateTimeOffset now, bool engineReady);
    public DictationAction OnHotkeyUp(DateTimeOffset now);
    public DictationAction OnOtherInputWhileHeld();

    public void OnSpeechDetected();

    public void OnTranscriptionFinished();         // → Idle
    public void Reset();                           // → Idle, clears flags
}
```
Transition table (this is the algorithm; the signatures don't determine it):

| State | Input | Action | Next |
|---|---|---|---|
| Idle | HotkeyDown, engine not ready | NotifyNotReady | Idle |
| Idle | HotkeyDown, ready | StartRecording | HoldRecording (pressedAt = now, SpeechSeen = false) |
| HoldRecording | HotkeyUp, held < TapThreshold | None | HandsFreeRecording (startedAt = pressedAt) |
| HoldRecording | HotkeyUp, held ≥ TapThreshold | StopAndPaste | Transcribing |
| HoldRecording | Tick with key not physically down | same as HotkeyUp at `now` | |
| HoldRecording | OtherInputWhileHeld | Cancel | Idle |
| HandsFreeRecording | HotkeyDown | None (secondTapHeld = true) | same |
| HandsFreeRecording | OtherInputWhileHeld | None (secondTapHeld = false) | same |
| HandsFreeRecording | HotkeyUp with secondTapHeld | StopAndPaste | Transcribing |
| HandsFreeRecording | Tick, secondTapHeld and key not physically down | StopAndPaste | Transcribing |
| HandsFreeRecording | Tick, !SpeechSeen and now − startedAt ≥ StrayTapTimeout | Cancel | Idle |
| HandsFreeRecording | Tick, now − startedAt ≥ HandsFreeLimit | StopAndSaveOnly | Transcribing |
| any active state | Escape | Cancel | Idle |
| Idle | Escape | None | Idle |
| Transcribing | HotkeyDown / HotkeyUp / Tick | None | Transcribing |

`TextInserter.InsertAsync` sequence:
1. Enter a `SemaphoreSlim(1)`, which serializes inserts.
2. `target = foreground.Capture()`.
3. If `target.IsElevated`: `SetText`, return `LeftOnClipboard`.

5. Poll every 10 ms (via `time`) until `!keys.IsAnyModifierDown()`, for at most 1 s.
