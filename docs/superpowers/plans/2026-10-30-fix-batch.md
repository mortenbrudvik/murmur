# Murmur 1.1.0 Fix Batch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the known dictation, failure-reporting and display bugs before 1.1.0 goes to the Store: instant pill, a 150 ms arm delay for lone-modifier hotkeys, a 5-minute hold limit, honest notices, visible hook failures, bounded TLS retries, fallback to the model on disk, layout-aware key names, paged history, a calm waveform, and setup/Settings polish.

**Architecture:** Mostly local changes in `DictationController`/`DictationStateMachine` (start path, arm phase, limits, notices), `WhisperEngine`/`ModelManager` (readiness, TLS, fallback), a small input-status surface (Core service + IPC + tray + web alert), `KeyNames` with an injectable layout, history paging through `GetHistoryRequest`, and the pill's level pipeline. Each task is test-first.

**Tech Stack:** .NET 10 (WPF, Autofac, MediatR 12.5.0, Serilog, NAudio, Whisper.net 1.9.1, H.NotifyIcon), React 19 + TypeScript + Vitest; xUnit v3 + Shouldly + NSubstitute + FakeTimeProvider.

**Spec:** `docs/superpowers/specs/2026-10-30-fix-batch-design.md`. Root causes with file:line evidence and test ideas, per item: `docs/superpowers/specs/2026-10-30-fix-batch-findings.md` (section numbers §6–§16 below refer to it; line numbers are as of 962a5bb).

5. **A dictation added between history pages** shifting an offset cursor — expected: "Show older" neither repeats nor skips entries. Test `Query_Before_IsStableWhenNewEntriesArrive` (Task 8).
