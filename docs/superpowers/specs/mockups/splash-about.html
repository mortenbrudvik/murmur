A splash and an about dialog for Murmur

Both grow out of the new icon. The line that forms the m is treated as a voice: on the splash it is spoken into shape, and in the about dialog it keeps humming quietly.

Splash: the voice becomes the letter

A lively speech waveform crosses the window, calms down and folds into the m. The tile lights up around it and the name is typed out, the way Murmur types for you.

When it shows

Only when you open Murmur yourself. A start at sign-in goes straight to the tray, as it does today, with no splash.

How long

Until the main window has drawn its first page, and at least 2.5 s so the name finishes typing. It does not wait for the speech model; the status line just reports it.

How it is built

A small borderless WPF window, 460 by 280, drawn natively so it is on screen before WebView2 has started. That start-up gap is the reason to have a splash at all.

The status line

The same wording the app already uses: "Loading model…", then "Ready · CUDA", or the download percent on a first run.

About: what is running, and where your words go

Shown inside the Murmur window. The header line hums slowly while the dialog is open. Close it and reopen it from the new About item in the sidebar.

Where it opens from

A new About item at the foot of the sidebar, and "About Murmur" in the tray menu, which brings the window forward with the dialog open.

Copy details

Puts the version, channel, model, runtime, graphics card and Windows build on the clipboard, ready to paste into a GitHub issue.

Dictated so far

The one playful line: a running count of the words Murmur has typed for you. It is counted from your history, so deleting entries or clearing the history lowers it.

How it is built

A React dialog in the existing UI, with one new call to the shell for the version, channel and data folder. Model, runtime and graphics card already reach the UI.

The history entries, the word count, the graphics card and the Store channel shown here are example values. In this mock-up "Open folder" does nothing; the three links and the name in the footer, which goes to brudvik.com, are real.
